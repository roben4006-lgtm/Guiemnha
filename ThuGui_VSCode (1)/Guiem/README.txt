DỰ ÁN THƯ GỬI 20/10 — VISUAL STUDIO CODE

Các tệp:
- index.html: cấu trúc trang web
- style.css: giao diện, màu sắc và hiệu ứng CSS
- script.js: hoạt ảnh, tương tác và hiệu ứng JavaScript

Cách mở:
1. Giải nén tệp ThuGui_VSCode.zip.
2. Mở Visual Studio Code.
3. Chọn File > Open Folder... rồi chọn thư mục ThuGui_VSCode.
4. Mở index.html và chạy bằng trình duyệt. Có thể cài tiện ích Live Server trong VS Code,
   sau đó nhấn chuột phải index.html > Open with Live Server.

Lưu ý:
- Đây là bản dự án tĩnh được tách từ mã HTML bạn đã gửi.
- Nếu trang gốc phụ thuộc tài nguyên bên ngoài không có trong mã nguồn, các tài nguyên đó
  vẫn cần kết nối internet hoặc bổ sung riêng.
- Để đổi nội dung chữ, tìm nội dung trong index.html hoặc các chuỗi trong script.js.
